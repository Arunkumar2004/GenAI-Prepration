Employee loan approval Prediction

Project Description
This machine learning project predicts employee may get loan or not using historical employee data.

Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab

Files
- project.ipynb : Main notebook
- dataset.xlsx : Dataset used for training

How to Run
1. Open project.ipynb in Google Colab.
2. Upload dataset.xlsx.
3. Run all cells.
